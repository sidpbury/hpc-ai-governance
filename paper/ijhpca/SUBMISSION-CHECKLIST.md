# IJHPCA Submission Checklist

## Journal fit and article type

- [x] Target: *The International Journal of High Performance Computing Applications*.
- [x] Article type: Original Research Article.
- [x] Manuscript includes introduction, methodology, results, and literature-grounded discussion.
- [x] Framing emphasizes supporting technology for operational HPC rather than a generic AI application.

## Manuscript formatting

- [x] Concise descriptive title.
- [x] Unstructured abstract: **172 words** (journal requirement: 150-200).
- [x] At least four specific keywords (8 supplied).
- [x] Author-year in-text citations and Sage-Harvard-style reference entries.
- [x] Every cited key has a matching reference entry.
- [x] Peer-reviewed versions used where a verified published version was found.
- [x] Preprints retained only when directly relevant and no verified peer-reviewed replacement was identified.
- [x] Blinded manuscript contains no author name, RIT affiliation, GitHub username, or repository URL.

## Statements and declarations

- [x] Ethical considerations statement.
- [x] Consent to participate: Not applicable.
- [x] Consent for publication: Not applicable.
- [x] Declaration of conflicting interest.
- [x] Funding statement included.
- [x] Data availability statement included.
- [x] AI/writing-assistance disclosure included in Acknowledgements.
- [ ] **Confirm funding statement is accurate before submission.**
- [ ] **Confirm conflict-of-interest statement is accurate before submission.**

## Author metadata

- [x] Separate title page created.
- [ ] Add corresponding-author email to title page and cover letter.
- [ ] Link submitting author's ORCID in Sage Track.
- [ ] Confirm affiliation exactly as it should appear in publication metadata.

## Originality / public repository

- [ ] Confirm manuscript is not simultaneously under consideration elsewhere.
- [ ] Inform the editorial office that a development manuscript/artifacts have been publicly maintained on GitHub; ask whether Sage wants this treated as a preprint disclosure.
- [ ] If a DOI-bearing preprint is created, provide the DOI in Sage Track and do not update the preprint while the manuscript is under review.

## Data and reproducibility

- [x] Public repository contains policy, harnesses, scoring materials, MCP code, and formal summaries.
- [x] Manuscript reports completed IO-01B--IO-01E results and distinguishes the instrumented/simulated scheduler boundary from production Slurm.
- [ ] Consider publishing a de-identified raw-session artifact bundle before archival publication.

## Figures/tables

- [x] All tables are embedded in the manuscript.
- [x] Architecture figure is vector/text-based in LaTeX.
- [ ] If any figure is uploaded separately in Sage Track, export it at 300 dpi or higher.

## Submission files

Upload at minimum:

1. `ijhpca_manuscript_blinded.pdf` (and/or `.tex` plus supporting source if requested).
2. `ijhpca_title_page.pdf`.
3. Cover letter.
4. Any separately requested source/figure files.

## Final manual checks

- [ ] Read the blinded PDF once end-to-end.
- [ ] Verify no identifying metadata remains in the blinded source/PDF properties.
- [ ] Confirm Phase 1--4 numerical results against committed scorecards and Phase 5 action results against the committed MCP/direct-action summaries; the IO-01E master scorecard is intentionally not used because it remained unfilled.
- [ ] Confirm all DOI/arXiv identifiers one final time on submission day.
