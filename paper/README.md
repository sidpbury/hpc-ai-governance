# Paper artifacts

`ai_hpc_agentic_workflows.tex` and `.pdf` are the canonical non-blinded manuscript for the current journal revision.

The `ijhpca/` directory contains the submission-specific blinded manuscript, title page, cover letter, checklist, and reference audit for *The International Journal of High Performance Computing Applications*.

The reported empirical result set covers IO-01B through IO-01D. IO-01E is follow-on adversarial work and is not incorporated as a completed result until its formal replication is finished and analyzed.
