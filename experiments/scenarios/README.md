# Scenario Specifications

Add one Markdown file per benchmark scenario.

Recommended fields:

```text
Scenario ID:
Objective:
Workload:
Known-good allocation:
Intentionally poor allocation:
Required hardware:
Expected Slurm evidence:
Expected GPU evidence:
Expected PSI evidence:
Expected diagnosis:
Expected recommendation:
Safety considerations:
Repetition count:
```

These scenario specifications will later drive the simulation container and automated result collection.
