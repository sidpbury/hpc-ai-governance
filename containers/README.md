# Simulation Container — Planned

This directory is reserved for a later reproducible benchmark container.

Planned contents:

- CPU stress/parallelism scenarios;
- memory-pressure scenarios;
- I/O and small-file scenarios;
- GPU utilization scenarios;
- GPU-memory pressure scenarios;
- balanced reference workloads;
- pinned dependencies and deterministic inputs.

Host and scheduler telemetry collection should remain capable of observing the container workload from outside the container.

No production container is included in the current project phase.
